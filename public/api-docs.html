Dokumentasi API Terpadu

Panduan Integrasi Endpoint Rawat Inap & Rawat Jalan (Vercel Node.js)

🌐 Base URL: /api/
🛡️ CORS Enabled
🏥 Rawat Inap 🦷 Rawat Jalan ⏱️ Realtime Trigger API

Informasi Umum

API ini menggunakan memori sementara (In-Memory Cache) di serverless Vercel. Data diperbarui melalui metode POST (biasanya oleh Scraper/Bot) dan dapat diambil informasinya menggunakan metode GET oleh aplikasi Frontend (Web/Mobile).

⚠️ Catatan Serverless: Karena sifat Vercel Serverless, variabel RAM akan direset secara berkala. Pastikan Scraper melakukan POST data setidaknya setiap beberapa menit sekali untuk menjaga data tetap fresh.

🏥 Data Rawat Inap

GET /api/Ranap

Mengambil data pasien Rawat Inap. Mendukung filter pencarian berdasarkan nama, no RM, dokter, dan tanggal.

Query Parameters

ParameterTipeStatusDeskripsi
cariStringOpsionalMencari nama pasien atau Nomor RM. (Case-insensitive)
dokterStringOpsionalFilter berdasarkan nama Dokter DPJP / Rawat Bersama.
tanggalStringOpsionalFormat YYYY-MM-DD. Filter berdasarkan tanggal masuk.

Contoh Request (Fetch JS)

const url = 'https://domain-anda.vercel.app/api/Ranap?cari=budi&dokter=isnoe';
const response = await fetch(url);
const result = await response.json();
console.log(result);

{
  "status": true,
  "total_data": 1,
  "last_updated": "24/10/2023, 14:30:00 WITA",
  "data": [
    {
      "ruangan": "VVIP A",
      "no_kamar": "Kamar 01",

POST /api/Ranap

Mengirim/Menyinkronkan data array JSON ke server. Digunakan oleh Scraper untuk mengupdate data In-Memory.

Body Request (application/json)

Tipe DataStatusDeskripsi
Array of ObjectsWajibArray yang berisi list JSON detail pasien.

Contoh Request Payload

[
  {
    "ruangan": "ICU",
    "no_kamar": "Bed 3",
    "nama_pasien": "Ahmad",
    "no_rm": "987654"
  }
]

Contoh Response (200 OK)

{
  "status": true,
  "message": "Ranap OK",
  "total": 1
}

⏱️ Trigger / Sinkronisasi Realtime

Endpoint: /api/trigger ini mengatur visibilitas state sinkronisasi hitung mundur (countdown) antar dashboard pengguna. Ketika Scraper di browser ekstensi aktif, Vercel akan broadcast trigger ke semua dashboard UI terhubung.

GET /api/trigger

Contoh Response (200 OK)

{
  "needsRefresh": false,
  "notify": "",
  "nextScrapeTime": 1698115200000,
  "isScraping": true,
  "lastUpdateStr": "24/10/2023, 14:30:00 WITA"
}
POST /api/trigger

Contoh Request Payload (Scraper ke Vercel)

{
    "isScraping": true,
    "lastUpdateStr": "24/10/2023, 14:30:00 WITA"
}
